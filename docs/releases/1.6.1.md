# Vex 1.6.1

## Highlights

- **Softer window frame.** A more subdued frame keeps the terminal workspace in focus.
- **Clearer active tabs.** Gradients are limited to active tabs, keeping inactive tabs visually quieter.

## Downloads

- `Vex-1.6.1-win-x64.msi` - Windows installer.
- `Vex-1.6.1-win-x64.zip` - portable, self-contained app; extract all files together and run `Vex.App.exe`.
- `Vex-1.6.1-win-x64.zip.sha256` - SHA-256 checksum of the portable archive.

No separate .NET installation is required. Supports Windows 10 1809+ and Windows 11 (x64).
