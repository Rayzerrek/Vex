# Vex 1.4.0

## Highlights

- **Sharper terminal fonts.** ClearType replaces forced grayscale antialiasing on the opaque terminal surface, making small monospace strokes less faint without changing font weight.
- **Fuzzy path picker (`Ctrl+Shift+F`).** Search files and folders in the current directory and insert a path without executing the command. Navigate into folders with `Tab` or `Right`, and move up with `Shift+Tab` or `Alt+Left` while keeping the query. Shell-aware quoting and raw insertion are supported; indexing is limited to the local Windows filesystem, not remote or Linux filesystems.
- **Safer closing.** Closing a tab or window can request confirmation when applications or coding agents are still running. Configure this in Settings.
- **Configurable copy on select.** Mouse selections copy automatically by default; disable this in Settings to keep them highlighted until an explicit copy. Keyboard selection and deletion now handle wrapped input, spaces, and Unicode graphemes correctly.
- **A streamlined workspace.** The project picker replaces the sidebar, with direct and sequential project switching. Workspace shortcuts also work while full-screen terminal applications are active.

## Performance and reliability

- Faster first-frame startup, background initialization, deferred popup creation, and smaller startup compilation images.
- Faster terminal snapshots and lower redraw allocations through packed-cell reads, cached glyphs, and immutable shared glyph spacing.
- More reliable shell prewarming, early input buffering, session teardown, and process-exit handling.
- Rendering fixes for synchronized output, scrolling, resizing, wide characters, combining marks, fractional glyph alignment, and DPI changes.
- Live chrome updates when switching appearance or themes; clipboard-lock handling, improved copy feedback, and delayed link previews.
- Recovery of malformed settings and session data, bounded prewarm buffers, and local managed-crash reports.
- Native ConPTY/OpenConsole packaging, including preservation of native sidecars across incremental publishes.

## Upgrade notes

**The built-in editor and file tree have been removed.** Vex now focuses on terminal workspaces. Legacy editor panes are migrated to terminal panes while preserving layout and focus. Use an editor inside the terminal or an external editor; `Ctrl+S` is passed through to the terminal application.

Existing settings and sessions are retained. The path picker uses a directory reported by shell integration or a recognized default prompt when available; otherwise it starts from the pane's initial directory.

- `Vex-1.4.0-win-x64.zip` — portable, self-contained app; extract all files together and run `Vex.App.exe`.
