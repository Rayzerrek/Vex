# Vex 1.5.0

## Highlights

- **Saved pane layouts.** Save and reuse terminal layouts with split panes, working directories, focus, and optional startup commands.
- **Program status.** Display status reported by shell integration and applications using OSC 7501, with bounded records and source labels.
- **Application icons across split panes.** Tabs stack icons for the applications running in their panes.
- **Refined workspace controls.** Settings use horizontal tabs, appearance controls have more space, and caption controls and icons render more consistently.
- **Consistent motion.** Workspace controls and overlays share transition timings and continue interrupted animations from the current frame.

## Performance and reliability

- Faster startup through composition warmup and a composite ReadyToRun image shipped beside the executable.
- More responsive terminal input during heavy output through paced redraws and nonblocking parser-lock retries.
- Fixed a crash when closing a tab after path completion and deferred focus loss.
- Improved copy feedback, including a light sweep and visibility over opaque terminal applications.
- Long tab titles retain space for application icons.
- Release archives preserve nested paths for the bundled OpenConsole host and shell integration scripts.

## Downloads

- `Vex-1.5.0-win-x64.msi` — Windows installer.
- `Vex-1.5.0-win-x64.zip` — portable, self-contained app; extract all files together and run `Vex.App.exe`.
- `Vex-1.5.0-win-x64.zip.sha256` — SHA-256 checksum of the portable archive.

No separate .NET installation is required. Supports Windows 10 1809+ and Windows 11 (x64).
