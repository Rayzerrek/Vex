# Vex 2.2.0

## Clearer text and more faithful terminal colors

- Apply foreground-aware DirectWrite gamma and contrast when compositing terminal
  text, instead of reusing a white-text mask's correction for every color.
- Resolve missing font families to an installed monospace fallback.
- Improve programming-font ligatures and the fit of mono and Nerd Font glyphs.
- Preserve neutral application backgrounds instead of mistaking them for host
  selections. This fixes mismatched input-panel backgrounds and half-block borders
  in applications such as OpenCode.
- Limit minimum text-contrast correction to light cell backgrounds; preserve dim
  text on dark and midtone surfaces.
- Avoid redundant ConPTY resize requests when only pixel metrics change.

## A more flexible workspace

- Smooth scrolling, pane dragging and animated pane transfers.
- Pane focus/zoom shortcuts and a configurable active-pane accent border.
- Smoother split opening, closing and focus transitions.
- Refined tab strip, window frame, pane headers, dialogs and tooltips, with a
  native Windows 11 Mica backdrop where supported.
- More balanced terminal padding, with edge-cell backgrounds extending into the
  surrounding padding.

## Terminal behavior and responsiveness

- Update libghostty-vt to 1.0.1.
- Improve startup responsiveness, VT parsing, terminal snapshots, glyph/geometry
  caching and path-picker indexing.
- Suspend unnecessary rendering for hidden windows and reclaim unused upload
  buffers.
- Expand TUI keyboard and OSC handling, route Escape on keydown, forward Alt
  chords and improve selection replacement while typing.
- Detect clickable URLs across soft-wrapped rows.
- Improve shell recognition, process captions and preservation of shell launches
  across workspace operations.
- Check for updates promptly at startup without delaying the initial window.

## Validation

The release workflow checks formatting, portable behavior and packaging, builds
Debug and ReleaseSafe, runs the compiled native tests on Windows, and packages
ZIP/MSI artifacts from the tested ReleaseSafe binaries. Offscreen rendering tests
cover text blending, mixed DPI, font fallback and cache reuse; terminal regressions
cover input-panel surfaces and half-block borders.

These checks do not establish visual parity with Ghostty or Windows Terminal on
every display, font and graphics driver.

## Install or update

Download `Vex-Native-2.2.0-win-x64.msi` or the matching portable ZIP. Installed Vex
can use **Updates: Check for Updates**, then **Update & restart** after verification.
Updating closes existing terminal sessions; running processes are not migrated.
Portable builds open the downloads page rather than installing an MSI.

Windows x64; no .NET runtime is required.
