# Vex 1.7.0 — legacy WPF

- Per-project WSL shell defaults and compact installed-shell pickers.
- Rounded overlays/popups and refined UI surfaces.
- Redesigned website with static documentation.

This release uses `Vex.App.exe` and JSON settings. The native rewrite starts
at [2.0.0](2.0.0.md), with a different configuration format and no session import.
