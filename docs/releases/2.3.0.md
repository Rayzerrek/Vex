# Vex 2.3.0

## Vertical tab sidebar and workspace layouts

- Add a collapsible vertical tab sidebar with application icons, drag reorder, and
  OSC 7501 activity status. The original horizontal tab strip remains available in
  **Preferences → General → Tab layout** and via **Tabs: Use Horizontal Tabs**.
- Save the default sidebar visibility in Preferences (`show_tab_sidebar`,
  `horizontal_tabs`), add **Tabs: Show Sidebar** / **Tabs: Hide Sidebar** (`Ctrl+Shift+B`),
  and make Tab Overview (`Ctrl+Shift+Space`) toggle cleanly.
- Animate tab creation and closure without delaying tab actions or resizing the
  terminal on animation frames; switching between existing tabs is immediate.
- Start new tabs at their final grid size, keep narrow horizontal tabs numbered,
  disable new-tab controls at the eight-tab limit, and cancel toolbar or caption
  clicks released outside the button.

## Streamlined Windows chrome and Compact density

- Flatten Compact window chrome, make its vertical sidebar narrower and immediate,
  make Compact split and zoom actions immediate, and keep activity glyphs static.
- Unify selection styling across the command palette and shell picker and remove
  motion from the command, shell, and path pickers.
- Expose the custom maximize button to Windows Snap Layouts and keep split drop
  outlines aligned with the hit target.

## Terminal links and safe paste

- Highlight soft-wrapped URLs and OSC 8 labels as one link target so `Ctrl+Click`
  on any visible segment opens the full destination.
- Preserve line breaks and tabs when bracketed paste is active; otherwise paste
  them as spaces instead of sending Enter or Tab.

## Validation

The release workflow runs `zig fmt --check`, portable checks, Debug and
ReleaseSafe cross-builds, Windows native tests, and ZIP/MSI packaging and
extraction verification. Local verification covered `zig fmt --check`,
`zig build`, `zig build test-build`, `zig build test`, `zig build test-portable`,
and Python packaging tests on Windows x64.

## Install or update

Download `Vex-Native-2.3.0-win-x64.msi` or the matching portable ZIP. Installed Vex
can use **Updates: Check for Updates**, then **Update & restart** after verification.
Updating closes existing terminal sessions; running processes are not migrated.
Portable builds open the downloads page rather than installing an MSI.

Windows x64; no .NET runtime is required.
