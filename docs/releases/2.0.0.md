# Vex 2.0.0 — native application

Vex moves from WPF to Zig/Win32, with ConPTY, libghostty-vt and D3D12.
Windows 10 1809+ / Windows 11 x64 is required; .NET is no longer needed to run it.

## Upgrading from WPF

- Download `Vex-Native-2.0.0-win-x64.msi` or the matching portable ZIP.
  The executable is `Vex.exe`, not `Vex.App.exe`; keep portable files together.
- Back up your old configuration before upgrading. JSON settings and session
  files are not imported. Configure preferences again in Settings or `init.lua`.
- Preferences and custom shell profiles persist. Project grouping, saved layout
  templates and session restoration are not available in this implementation.
  Closing Vex ends its terminal processes.
- The MSI retains the installer identity and install location. Preview packages
  are not a side-by-side installation; test them on an isolated machine.

See the [configuration guide](https://github.com/Rayzerrek/Vex/blob/v2.0.0/docs/configuration.md)
and [website guides](https://github.com/Rayzerrek/Vex/blob/v2.0.0/web/README.md) for setup.
