# Vex 2.0.2

## Native updates

- Check published stable releases in the background or use **Updates: Check for Updates** in the command palette.
- Download and verify updates without blocking terminal rendering; installed MSI builds offer **Update & restart** (`Ctrl+Shift+U`). Portable builds offer the downloads page instead.
- Review active programs before restarting. Cancelling leaves sessions running; restarting does not migrate terminal processes or restore their contents.
- Verify package size, SHA-256, MSI product identity, platform and version before installation. Serialize installation, protect the verified package and retain its MSI source for repair and rollback.

## Shared notifications

- Updates, errors, configuration warnings and session completion use compact, theme-aware notifications with X dismissal, hand cursors, hover feedback and short animations.
- Stack transient notices above pending updates without overlap. Reuse text layouts and glyph masks instead of rerasterizing text during hover.
- Preserve final terminal output without adding blank lines; keep **Session finished** or **Process exited** in the header after the notice closes.

## Install

Download `Vex-Native-2.0.2-win-x64.msi` or the matching portable ZIP. No .NET runtime is required.

**Existing 2.0.1 and older installations need this MSI installed once over the current installation** to gain the updater. Do not uninstall first. Later updater-capable versions can discover future published releases automatically.

See [native updates](../updates.md) for restart behaviour, recovery and the HTTPS/hash trust boundary. Windows 10 runtime and direct UAC-denial scenarios have not yet been exercised; the local desktop checks ran on Windows 11.
