# Vex 2.1.1

## Faster, more reliable path picking

- Index shallow paths before deep trees, and show partial results while scanning continues.
- Reuse recent folder indexes within the picker and filter existing candidates when extending a search.
- Keep the selected path stable when partial or final results reorder the list.
- Avoid recursively scanning dependency/cache/VCS trees such as `node_modules`, `.git` and `.venv`, and system/mount directories at the WSL distribution root. These directories remain listed and can be opened explicitly.
- Follow the WSL shell's current directory after `cd`, including when OSC 7 integration is unavailable.
- Improve Unicode and Windows-reserved Linux filename handling, path navigation, and shell-specific quoting.
- Open Linux directory symlinks even when the Windows 10 WSL share cannot follow them natively. Resolution happens only when opening a link, and browses its canonical directory target; file links remain insertable.

## Other fixes

Improve shell-handoff and orphaned-command detection so process status and close protection follow the active shell more accurately.

## Validation

The changes passed 285 native Windows tests in both Debug and ReleaseSafe, portable tests, Python tests, and ZIP packaging verification locally. A local Windows/WSL desktop check covered partial results, selection stability, cached navigation, current-directory tracking, reserved filenames, directory/file links, broken links, and self-referential links.

## Install or update

Download `Vex-Native-2.1.1-win-x64.msi` or the matching portable ZIP. Installed Vex can use **Updates: Check for Updates**, then **Update & restart** after verification. Updating closes existing terminal sessions; running processes are not migrated. Portable builds open the downloads page rather than installing an MSI.

Windows x64; no .NET runtime is required.
