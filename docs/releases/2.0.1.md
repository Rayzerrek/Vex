# Vex 2.0.1

## Tabs and settings

- Rename tabs inline with a visible caret, select-all, Home/End, UTF-8 cursor movement, word deletion and clipboard shortcuts.
- Clear a custom name to restore the live terminal or reported task title.
- Settings now use labeled cards for sessions, behavior, terminal text and cursor controls, with compact layouts and inline font-size feedback.

## Performance and reliability

- Cache the active rename editor's DirectWrite layout across repaints and cursor moves; rebuild only when text or font changes.
- Avoid redundant settings-page refreshes during relayout and stop scheduling invisible rename exit animations.
- Failed clipboard writes no longer discard a name during Cut. Pasted names reject control characters.
- Improve icon contrast, render Pi in color, soften TUI highlights across theme changes and clear terminal selection after copying.

## Install

Download `Vex-Native-2.0.1-win-x64.msi` or the matching portable ZIP. No .NET runtime is required.

Upgrading from the legacy WPF application? Read the [2.0.0 migration notes](2.0.0.md); legacy settings and sessions are not imported.
