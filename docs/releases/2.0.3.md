# Vex 2.0.3

## Updates

- Dismiss **You're up to date** automatically after five seconds instead of leaving it on screen indefinitely.
- Give each new check result its own timeout; keep downloaded updates visible until dismissed or installed.
- Add Windows desktop regression coverage for expiry, repeated checks, idle rendering and persistent update prompts.

## Install

In an installed Vex 2.0.2, choose **Updates: Check for Updates** from the command palette, then **Update & restart** once the download is verified. Restarting closes terminal sessions and does not migrate running processes.

Alternatively, download `Vex-Native-2.0.3-win-x64.msi` or the matching portable ZIP. Portable builds open the downloads page rather than installing an MSI. No .NET runtime is required.
