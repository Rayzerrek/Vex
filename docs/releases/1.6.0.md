# Vex 1.6.0

## Highlights

- **Refined terminal workspace.** Roomier tabs, softer pane dividers, and native rounded window corners on Windows 11, preserving Vex's existing color palette.
- **Clearer tab titles.** Session names retain their full text, file and directory titles are more readable, and tooltips preserve the original terminal title.
- **More reliable application icons.** Folder names no longer override application detection, and bundled icons preserve their proportions.
- **Editor icons stay with the editor.** Neovim keeps its own icon when a TypeScript language server is running underneath it. Process tracking and close confirmations also recognize the editor instead of its child services.
- **Improved WSL integration.** Distribution-aware project paths and launch arguments, more consistent shell detection, and dedicated WSL artwork.
- **Copy feedback from terminal applications.** Vex recognizes application clipboard updates and supports copying text through OSC 52, with visual feedback over the copied text or at the cursor.

## Downloads

- `Vex-1.6.0-win-x64.msi` - Windows installer.
- `Vex-1.6.0-win-x64.zip` - portable, self-contained app; extract all files together and run `Vex.App.exe`.
- `Vex-1.6.0-win-x64.zip.sha256` - SHA-256 checksum of the portable archive.

No separate .NET installation is required. Supports Windows 10 1809+ and Windows 11 (x64).
