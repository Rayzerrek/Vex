# Vex 2.1.0

## Terminal images

Vex now displays images sent with the Kitty Graphics Protocol's direct transmission
mode. The initial implementation supports RGB, RGBA and PNG, chunked transfers,
image replacement/deletion, multiple placements, source cropping, pixel offsets,
scaling, transparency, z-order and scrolling.

Textures are cached by image generation: unchanged images are not decoded or
uploaded again on each frame. Consecutive placements of the same image are
batched. Image transfers use bounded, fence-protected upload buffers separate
from terminal text geometry. Kitty replies are delivered through ConPTY without
being consumed by its input parser.

File, temporary-file and shared-memory transfers are disabled. Applications must
use direct image transmission. Unicode placeholders, animation and relative
placements are not supported by this integration. See
[the integration notes](../kitty-graphics.md) for limits and a local smoke check.

## Other improvements

- Faster application icon detection.
- Automatically dismiss the up-to-date notification after five seconds.

## Validation

Windows native tests cover PNG decoding and alpha, cache invalidation, allocation
failures, primary/alternate screen isolation, crop/scroll geometry, ConPTY delivery
and offscreen D3D12 WARP rendering, including image-transfer budget pressure and
in-flight texture retirement. Hardware benchmarks and interactive compatibility
checks are separate local validation, not application-wide performance guarantees.

## Install or update

Download `Vex-Native-2.1.0-win-x64.msi` or the matching portable ZIP. Installed Vex
can use **Updates: Check for Updates**, then **Update & restart** after verification.
Updating closes existing terminal sessions; running processes are not migrated.
Portable builds open the downloads page rather than installing an MSI.

Windows x64; no .NET runtime is required.
